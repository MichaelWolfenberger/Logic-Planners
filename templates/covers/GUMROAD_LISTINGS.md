## HOW TO CREATE EACH LISTING
1. Go to gumroad.com → Dashboard → New Product → Digital Product
2. Paste the Title
3. Set the Price
4. Paste the Description into the description box
5. Upload the Cover Image (from templates/covers/)
6. Upload the Template File (from templates/{category}/)
7. Add Tags
8. Click Publish

# Etsy Bundle Listings — One Per Category

Etsy strips markdown. When pasting into the listing description field, replace `###` headers with the bold/emoji line as-is (Etsy renders emoji fine) and replace `*` bullets with `•` or `-`.

Each bundle includes the category's standalone templates. Sell the standalone templates as separate listings too — these bundle listings should link to them once published.

Ready-to-upload bundle files (ZIP per category, each with a buyer README) live in `templates/bundles/`.

**Description:**

FAQ

Common questions.

Do these work if I don't have a standard 9-to-5 schedule?

Yes — the daily planner has no fixed start time. Define your working window in the Setup tab (e.g., 2 PM–10 PM or 5 AM–1 PM). The time block template is especially useful for non-standard schedules since it organizes by category, not clock time.

How much can I actually customize?

Quite a lot. Working hours, all task and block category names, habit list (up to 30), habit frequency targets, priority scoring weights, and review cadence are all configurable from the Setup tab. Everything else in the template references those values — change them once, and the whole file updates.

Can I use the daily planner for multiple people?

Each file is designed for one person. To use it for a team, duplicate the sheet tabs and rename them. All formulas are independent per-tab — no cross-tab dependencies to break.

What if I want more than 30 habits in the tracker?

Duplicate the last row — the formulas extend automatically. There's no built-in cap beyond what your screen can show. No manual formula editing required.
